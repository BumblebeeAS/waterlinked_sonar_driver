## [0.1.0] - 2026-09-02

### Added

- Lifecycle node and component publishing point clouds, range images, signal-strength images, camera info and IMU samples from a Sonar 3D-15.
- Services to enable acoustics, switch imaging frequency and set the imaging range.
- Diagnostics for the receiver and the sonar's temperature and status.
- Read-only parameters generated with `generate_parameter_library`, a launch file and a default parameter file.
